# CloudOps Manager

Plateforme de gestion d'infrastructure cloud : équipes, projets, environnements,
serveurs, applications, monitoring et alertes.

## Stack
- **Backend** : NestJS, TypeORM, PostgreSQL
- **Frontend** : Next.js (App Router), TypeScript
- **DevOps** : Docker, Docker Compose, GitHub Actions

## Structure
- `api/` : API REST NestJS
- `web/` : application Next.js
